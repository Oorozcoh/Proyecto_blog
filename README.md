# Blog Django - Proyecto Final

## Funcionalidades
1. Listar Posts
2. Acerca de mi
3. Buscar Posts por (título, Autor, Categoría)
4. Crear Autores (Necesita estar logueado)
5. Crear Categorías (Necesita estar logueado)
6. Crear Posts (Necesita estar logueado)
7. Ver mensajes (Necesita estar logueado)
8. Enviar mensajes (Necesita estar logueado)
9. Editar perfil (Necesita estar logueado)


## Orden para probar
1. Crear autor
2. Crear categoría
3. Crear post
4. Buscar post por (título, Autor, Categoría)
5. Ver mensajes recibidos
6. Enviar mensaje a un usuario registrado
7. Edite su perfil de autor y cambie su (Nombre, Apellido, Corre electrónico, Avatar o su contraseña)

## Base de datos
SQLite3 (por defecto en Django)

## Patrón
Modelo - Vista - Template (MVT)
